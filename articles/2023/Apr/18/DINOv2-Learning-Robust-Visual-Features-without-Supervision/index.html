🦕 DINO v2: Match and transfer features across domains and understand relations between similar parts of different objects

Date Tue, 18 Apr 2023 Modified Thu, 03 Sep 2026 By Michał Chromiak Category Computer Vision Tags Representation Learning / Self-Supervision (SSL) / CV / ViT / GPT / WSL / Weak-supervision / Scalability


Figure 1. DINOv2 data-processing pipeline: embed, deduplicate, retrieve, and combine curated and uncurated images.

The paper in one sentence🔗

DINOv2 shows that an existing discriminative self-supervised recipe can produce unusually transferable image and patch features when it is trained with a large, carefully curated image collection and scaled with a stable, efficient implementation.

The primary reference is "DINOv2: Learning Robust Visual Features without Supervision" by Maxime Oquab and colleagues. It was submitted to arXiv on 14 April 2023, revised in February 2024, and published in Transactions on Machine Learning Research (TMLR) in 2024. The OpenReview record contains the publication history, and the authors provide the official implementation and checkpoints.

DINOv2 is not the first application of self-supervised learning to images. It builds directly on earlier methods including DINO, iBOT, MAE, SEERv2, MSN, EsViT, and Mugs. The paper's narrower contribution is to close much of the benchmark gap between self-supervised features and openly available weakly supervised features such as CLIP, OpenCLIP, and SWAG, while keeping the visual backbone useful in a frozen state.

TL;DR🔗

  • DINOv2 is a family of ViT-S/14, ViT-B/14, ViT-L/14, and ViT-g/14 image encoders. The largest backbone has about 1.1 billion parameters.
  • Pretraining uses images alone: no class labels or captions enter the DINOv2 learning objective.
  • The core objective combines image-level DINO self-distillation, patch-level masked iBOT self-distillation, and a KoLeo feature-spreading regularizer.
  • The 142-million-image LVD-142M training set is not an arbitrary web scrape. It is produced from a 1.2-billion-image pool using filtering, deduplication, curated seed datasets, and self-supervised image retrieval.
  • Compared on the same hardware with the iBOT implementation, the DINOv2 implementation runs about 2 times faster and uses one third of the memory.
  • Many evaluations freeze the backbone, but "frozen" does not mean that every downstream task is training-free. Classification, segmentation, and depth experiments commonly train a linear classifier, decoder, or adapter on top.
  • Instance retrieval is the clearest training-free example: database images are ranked directly by cosine similarity between frozen image features.
  • Patch features often align corresponding object regions across pose, style, domain, and even different object categories. This is compelling qualitative evidence, but it should not be interpreted as proof of human-like semantic understanding.

Figure 2. Qualitative comparison of semantic-segmentation outputs obtained with DINO and DINOv2 features. This is a visual comparison, not a reported precision metric. (Source)

What "without supervision" means🔗

DINOv2 learns its backbone without image labels or paired text. That is different from CLIP-style pretraining, where captions provide a weak semantic signal. Avoiding text lets the objective retain local visual information that may never be mentioned in a caption, and it permits training on image collections that have no descriptions.

There is an important qualification: the learning objective is label-free, but the data pipeline is curated. The final dataset is shaped by seed datasets, filtering rules, deduplication, and similarity retrieval. The results therefore do not show that the same feature quality will emerge from any uncurated image collection.

The DINOv2 learning objective🔗

DINOv2 is best understood as a teacher-student system operating at two spatial scales. A student network is optimized by gradient descent. The teacher has the same basic role as in DINO and is updated from an exponential moving average of the student. Different crops of the same source image provide related views.

Image-level DINO loss🔗

The class token from each network passes through its DINO projection head. After normalization, \(p_s\) and \(p_t\) denote the student's and teacher's probability vectors over learned prototype coordinates. The paper writes the cross-entropy term as:

$$ L_{DINO} = -\sum p_t \log p_s. $$

The summation over prototype coordinates and the comparisons between suitable teacher and student crops are implicit in this compact notation. The student learns to match the teacher's representation of another view of the same image.

Patch-level iBOT loss🔗

Some input patches are masked for the student but remain visible to the teacher. At each masked patch index \(i\), the student predicts the teacher's distribution for the corresponding visible patch. The paper writes:

$$ L_{iBOT} = -\sum_i p_{ti} \log p_{si}, $$

where \(i\) ranges over masked patch positions. DINOv2 uses separate learnable projection heads for the image-level DINO objective and the patch-level iBOT objective; unlike the original iBOT ablation, the authors found that untying these heads worked better at scale.

Centering and KoLeo regularization🔗

The teacher outputs use Sinkhorn-Knopp centering, run for three iterations in the reported recipe, while the student uses softmax normalization. This helps avoid representational collapse.

DINOv2 also applies the KoLeo regularizer to spread class-token features within a batch. For \(n\) feature vectors \((x_1,\ldots,x_n)\), the paper defines:

$$ L_{\mathrm{KoLeo}} = -\frac{1}{n}\sum_{i=1}^{n}\log(d_{n,i}), $$

with

$$ d_{n,i} = \min_{j\neq i}\lVert x_i-x_j\rVert. $$

The features are \(\ell_2\)-normalized before this distance is computed. In the paper's ablation, KoLeo especially improves nearest-neighbor retrieval, while the masked iBOT term is important for dense prediction.

High-resolution adaptation🔗

Small objects can disappear at low resolution, but full high-resolution pretraining is expensive. The final recipe therefore includes a short adaptation stage at \(518\times518\) pixels near the end of pretraining. This improves pixel-level transfer without paying the cost of high-resolution training throughout the run.

Building LVD-142M🔗

The training corpus contains 142 million images, but its construction is as important as its size:

  1. The authors collected a raw web pool and applied URL filtering, near-duplicate removal, NSFW filtering, and blurring of identifiable faces, yielding about 1.2 billion unique images.
  2. They removed near-duplicates of the test and validation images used in the paper's benchmarks.
  3. Curated sources included ImageNet-22k, the ImageNet-1k training split, Google Landmarks, and several fine-grained datasets.
  4. A self-supervised ViT-H/16 pretrained on ImageNet-22k embedded the images. Cosine similarity and k-means connected the uncurated pool to the curated sources.
  5. For a sufficiently large query dataset, the pipeline usually retrieved four nearest neighbors per query. Smaller sources used cluster-based sampling, with balancing limits.

The pipeline uses image similarity rather than captions, hashtags, or class annotations. It also depends on the composition of the curated seed collections; "no metadata in the pipeline" should not be confused with "no curation choices."

The paper reports that deduplication and retrieval used Faiss on 20 nodes, each with eight V100-32GB GPUs, and took less than two days to produce LVD-142M.

Scaling the model and implementation🔗

Scaling discriminative self-supervision exposed memory, numerical-stability, and throughput problems. The reported implementation addresses them with several complementary techniques:

  • Memory-efficient attention. The authors implemented a FlashAttention-style kernel (Dao et al., 2022). To suit GPU kernels, ViT-g uses an embedding dimension of 1536 with 24 heads, or 64 dimensions per head. The resulting backbone has about 1.1 billion parameters.
  • Sequence packing. Global crops at resolution 224 and local crops at resolution 98 produce sequences of different lengths. DINOv2 concatenates them and uses a block-diagonal attention mask, making the computation equivalent to separate forwards while improving efficiency. The low-level components are provided by Meta's xFormers library.
  • Efficient stochastic depth. Rather than calculate every residual branch and mask selected results, the implementation skips computation for dropped residuals. With the reported drop rate of 40%, this saves both compute and memory.
  • Fully Sharded Data Parallel. FSDP shards the student, teacher, and AdamW optimizer states across GPUs. Model shards remain in float32; backbone weight broadcasts and gradient reductions use float16, while projection-head gradients are reduced in float32 for stability.

The frequently quoted efficiency result has a specific scope: on the same hardware and relative to the iBOT implementation, DINOv2 runs about \(2\times\) faster while using \(1/3\) of the memory. It is not a universal comparison with every self-supervised method or implementation.

Distilling the smaller models🔗

The ViT-g/14 model is trained from scratch. Smaller ViT-S/14, ViT-B/14, and ViT-L/14 models are distilled from the frozen ViT-g teacher rather than trained independently from scratch, following the general idea of knowledge distillation.

For this stage, the teacher is fixed, masking and stochastic depth are removed, the iBOT loss is applied on the two global crops, and an exponential moving average of the student becomes the released model. In the paper's ablation, the distilled ViT-L/14 beats a ViT-L/14 trained from scratch across all 12 reported benchmarks.

What the experiments establish🔗

The experiments cover image classification, domain generalization, fine-grained classification, video action recognition, instance retrieval, semantic segmentation, and monocular depth estimation. Comparisons should always be read together with the architecture, pretraining data, input resolution, and downstream evaluation protocol.

Image classification🔗

With a frozen backbone and a trained linear classifier at resolution 224, DINOv2 ViT-g/14 reaches 86.5% ImageNet-1k top-1 accuracy. In the same evaluation table:

  • iBOT ViT-L/16 reaches 82.3%, so the reported improvement over the previous SSL result is 4.2 percentage points;
  • OpenCLIP ViT-G/14 reaches 86.2%; and
  • EVA-CLIP ViT-g/14 reaches 86.4%.

Thus DINOv2 is competitive with, and narrowly ahead of, those weakly supervised baselines under this linear-evaluation protocol. It does not dominate every weakly supervised model on every dataset.

Fine-tuning remains useful. Supervised end-to-end fine-tuning raises ViT-g/14 from 86.5% to 88.5% at resolution 224 and from 86.7% to 88.9% at resolution 448. The appropriate conclusion is that fine-tuning is optional for strong performance, not that it is ineffective or that downstream learning is unnecessary.

Classification beyond ImageNet and video🔗

The paper trains linear classifiers on frozen DINOv2 features for iNaturalist, Places205, and 12 additional transfer datasets. DINOv2 is particularly strong on fine-grained categories, but OpenCLIP remains better on some benchmarks such as SUN and Stanford Cars.

For video action recognition, the image backbone is still frozen, but a linear classifier is trained. The protocol averages features from eight frames for UCF-101 and Kinetics-400, and concatenates them for Something-Something v2 to retain temporal ordering. These results show that image features transfer to video classification; they do not mean that DINOv2 was pretrained to model video dynamics.

Instance retrieval🔗

Instance retrieval is genuinely non-parametric in the reported setup. Database images are ranked by cosine similarity to a query feature, without training a task-specific retrieval head. On Oxford-Hard, the strongest reported DINOv2 result improves by roughly 41 mAP points over the selected SSL baseline and 34 points over OpenCLIP.

The photograph on the right is the query. The numbered panels on the left are its ten highest-ranked database matches, ordered by similarity in the frozen DINOv2 feature space. Although the results vary in medium, color, pose, and background, all depict horses; several also preserve the side-on pose or a multi-horse composition. This is a qualitative example of cross-domain visual similarity, not by itself a quantitative retrieval result or proof that the model represents a symbolic concept of a horse.


Figure 3. Instance-retrieval example. Right: a query photograph of a gray horse and a brown horse in a field. Left: ten retrieved horse images, ranked 1-10 by similarity in the frozen DINOv2 feature space. The matches span photographs, paintings, and line drawings while retaining the subject and some pose or composition cues.

Semantic segmentation🔗

The backbone remains frozen, but the segmentation predictor is trained with semantic labels. The paper evaluates:

  • a linear layer on patch tokens;
  • a stronger multiscale linear setup using the last four transformer layers, a larger input, and multiscale inference; and
  • a trained ViT-Adapter plus Mask2Former head on top of the frozen backbone.

The multiscale ViT-g/14 result reaches 53.0 mIoU on ADE20K, close to MAE with end-to-end UperNet fine-tuning at 53.6. The adapter/Mask2Former system reaches 60.2 mIoU while keeping 66% of the weights frozen, compared with the cited state of the art at 62.9. These are strong frozen-backbone results, but they are neither clustering nor training-free semantic segmentation.


Figure 4. Semantic segmentation produced by a task-specific predictor operating on frozen DINOv2 features.

Monocular depth estimation🔗

Depth prediction also keeps the DINOv2 backbone frozen while training a downstream predictor. The paper compares a linear head over one transformer layer, a linear head over four layers, and a DPT decoder.

With DPT, DINOv2 ViT-g/14 reports RMSE 0.279 on NYU Depth v2, 2.11 on KITTI, and 0.338 for transfer from NYU Depth v2 to SUN RGB-D. The reference results printed above the table are 0.330, 2.10, and 0.421 respectively. DINOv2 therefore improves the referenced NYU and transfer results and essentially matches, but does not beat, the referenced KITTI result. Lower RMSE is better.

What the patch correspondences mean🔗

The paper visualizes patch features with principal component analysis (PCA). It thresholds the first principal component to separate foreground from background, then maps three subsequent components to color channels. Similar colors frequently appear on corresponding regions across related images.


Figure 7. PCA visualization of DINOv2 patch features. Similar colors indicate aligned feature directions, not predefined semantic labels.

For explicit patch matching, the authors compute Euclidean distances between patch features from two images, solve an assignment problem, and retain salient matches with non-maximum suppression. Examples connect wings to wings, heads to heads, and functionally similar regions across photographs, drawings, poses, and even different objects.

This supports the claim that local DINOv2 features encode useful correspondences across domains. Terms such as "understands object parts" should remain shorthand for this measured behavior. PCA plots and selected matches alone do not prove symbolic, causal, or human-like understanding.

Applications and appropriate usage🔗

DINOv2 is well suited as a reusable visual backbone for:

  • image and video classification with a trained probe;
  • non-parametric instance retrieval;
  • semantic segmentation with a trained linear head or decoder;
  • monocular depth estimation with a trained head;
  • object detection and other dense tasks using adapters or decoders; and
  • specialized domains where labels or captions are scarce.

Cellular imaging is a plausible example of the last category, but the paper does not demonstrate biological discovery or train a cellular foundation model. It should be presented as a potential application rather than an experimental result.

Limitations, bias, and cost🔗

The paper includes limitations that are essential to interpreting its foundation-model claims:

  • Geographical and income bias remains. On Dollar Street, the ViT-g model has a 25.7-point performance gap between Africa and Europe and a 31.7-point gap between low- and high-income households. It improves on the selected SEERv2 baseline but remains biased toward wealthier households in Western regions.
  • The human-attribute analysis is limited. A linear classifier showed no clear harmful-label pattern across the evaluated gender, skin-tone, and age groups, but the authors explicitly state that a more thorough analysis could reveal additional flaws.
  • Training is expensive. Under the paper's standardized assumptions, reproducing one DINOv2-g run requires 22,016 A100 GPU-hours, about 9.7 MWh, and an estimated 3.7 tonnes of CO2 equivalent. The estimate covers GPU electricity and excludes hardware manufacturing and disposal.
  • Qualitative correspondences are not a complete semantics evaluation. Selected PCA and patch-matching examples establish an interesting property, not a general theory of object-part understanding.
  • The representation is not language-aligned. Because pretraining uses no text, DINOv2 does not by itself provide CLIP-style open-vocabulary labels. A separate supervised or language-alignment component is required when an application needs named concepts.

Conclusions🔗

DINOv2's main achievement is not a new architectural block. It is a carefully integrated system: DINO and iBOT teacher-student objectives, KoLeo regularization, high-resolution adaptation, curated data at scale, an efficient distributed implementation, and distillation from a 1.1-billion-parameter ViT-g teacher.

The resulting frozen representations are unusually versatile. They work for global classification, local dense prediction, cross-domain transfer, and nearest-neighbor retrieval. The correct scientific interpretation is that the backbone often transfers without being fine-tuned; most semantic downstream tasks still learn a task-specific readout.

Future research🔗

The authors propose that object-part and scene-geometry properties may continue to improve with model and data scale, drawing an analogy to emergent abilities in language models (Wei et al., 2022). This is a research hypothesis, not a result established by the current scaling experiments.

They also suggest connecting frozen visual features to a language-enabled system that can process them like tokens. That direction requires an additional alignment or multimodal training stage; it is not a capability of the original DINOv2 model itself.
